# 基础排版样例

输入 **原稿.docx**。严格离线时选择“本地精细工作台”，使用SCUT演示规则或导入“排版要求.json”，核对正文/标题及内容表格范围后检查、选择安全项并预演采用。表格1是内容表格；软件声明保持待核对。可对照独立错误清单中的字体、字号、行距、缩进、纸张和边距。

无API配置时也可在智能入口上传原稿→默认常规整理→开始→下载。本次实际新上传用的就是这条降级路径，没有规范解析或结构请求，没有Word。已配置API时该入口可能分析软件声明；要保证0API请用本地工作台。

结果为 **修正版.docx**、**报告.html**。实际33项属性修改，仍有1个问题、9项待复核；不代表全文合格。原稿、图片、表格文字和未选部件独立核对保持。**修改摘要.md**说明实际边界，不是新增学校规范。

保存要求只保存规则，恢复不恢复执行授权。无需安装Word、生成PDF或输入API密钥。
