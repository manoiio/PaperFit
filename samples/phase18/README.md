# 目录软件演示样本

全部为合成内容，无真实作者。`manual-correct.docx`只表示本轮R30–R32目录属性正确，不表示整篇符合R01–R29或真实页码正确。

- manual-errors.docx：独立注入6项错误，具体位置、前后值见 independent-errors.json；包含后半run、字符样式继承、固定20pt行距。d:2目录标题、d:3一级、d:4二级、d:5三级。
- manual-correct.docx：相同内容及对象的目录正确对照。
- automatic.docx：SDT中的3个TOC样式缓存段落，跨段复杂TOC域、3个内部书签链接及嵌套PAGEREF。只读；不刷新。d:N纳入SDT，旧顶层段号不变；正文标题是顶层段3、5、7。
- correspondence-cases.docx：由正确手工样本构造两个同名正文标题；同名多候选、未找到和未知级别的只读核对例。对应.scope.json是显式演示范围。
- broken-fields.docx：自动目录外层TOC缺少结束边界，首条超链接目标与PAGEREF目标不一致；不能以人工确认绕过只读/结构保护。

手工样本顶层段6/8/10为正文Heading1/2/3，7/9/11为正文，2–5仅目录。网页上传不会按文件名套用这些清单；必须人工核对。示例中的保存页码1只是文本，不是实际页码验收答案。段前后间距、标题蓝色、目录制表位等未选属性保留；不能把保留的样本外观当作官方范例。

更多最小保护例见tests/test_toc.py：主题语言、特殊文字、锁定SDT、表格内目录线索、自动编号、范围冲突、项目恢复和双会话隔离。原段落内容、域代码及书签、表格/媒体和未选属性由独立XML/ZIP读数验证。
