# 正文引文合成软件演示样本

errors/correct仅分别表示安全普通引文的错误与正确对照，不表示R01–R34或复杂域/全文排版全部合格。均为软件演示，无真实作者或文献。

独立定位：顶层段3含两次[1]和应排除的数组[8]；段4跨run部分上标[2]；段5含字符样式上标[1]和基线[3]；段6为REF只读缓存[1]。参考文献标题段7、条目段8–17。错误样本4处安全上标问题。

risks增加段7的[5]再[4]、组合/区间/全角候选，段8含书签；条目移至10–20，末条重复[4]。这些只用于只读边界，不自动改编号。protected在errors基础上增加实际图片、合并单元格、有效RefOne书签和连续分节，验证实际包对象保留。

independent-errors.json为作者先验清单；未将新模块输出复制成标准答案。构建与全部验收索引见outputs/phase19。修正版保留所有非所选属性；REF在LibreOffice预览中可能重新求值，与Word保存缓存显示不同，未回写源文件。

automatic-and-field.docx含实际ListNumber自动编号参考条目及跨段REF缓存，仅用于只读保护和不确定性展示；不从手工2–10子序列判断自动条目是否为1，不修改域或编号。LibreOffice预览求值可改变显示缓存，但不会回写源DOCX。
