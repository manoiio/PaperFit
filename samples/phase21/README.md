# Word注释软件演示样本

全部为脱敏合成，不是真实课程论文。

- errors.docx：3条脚注、3条尾注；按独立构造清单注入9项普通文字格式错误。
- correct.docx：上述普通文字属性正确；尾注3含内部链接，仍有结构/行距两条待复核，不能称全文零待复核。
- protected.docx：额外合法REF域注释，域缓存只读，不用于证明安全域修正。
- broken.docx：重复注释ID和缺失目标，仅用于只读保护验收，**不作为合法Word展示输出**。
- independent-errors.json：构造者事先指定的位置、属性和保护对象，不复制检查器输出。

主文档6个顶层段落，带真实图片、简单表格、书签和正文引用；脚注/尾注内部段落不占这6个编号。每类另有separator及continuationSeparator系统对象。

仅检查注释的演示可把6个顶层段落明确设为“其他”，选择所有6条普通注释。现有单文档规则仍会报告没有确认的摘要/关键词等边界，以及R22参考文献数量问题；这些不是本轮修正目标。R36/R37正确不等于其他要求已通过。
