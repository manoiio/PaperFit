# PaperFit · 论文有格

在本机检查并整理 Word 论文，另存修正版，保留原稿。支持普通文字和段落、已确认图表/注释，以及明确选择后的安全编号、分区页码和目录更新。结果会说明修改了什么、哪些仍需人工判断；“0个问题”只表示已启用检查项未发现问题，可展开查看未配置及未覆盖范围；不承诺任意论文全文合格。

## 从这里开始

当前 Mac 已有运行环境：**双击仓库内的 [启动论文有格.command](启动论文有格.command)**。启动成功会打开 [本机网页](http://127.0.0.1:8501/)。已运行时直接复用；其他程序占用端口时会提示，不会结束进程。启动器使用现有 `.venv`，不安装、升级或重建环境。首次接手一台没有环境的电脑，请由维护人员按 [技术说明](TECHNICAL_HISTORY.md#安装与运行)准备依赖。

网页的“环境自检与恢复”可查看基础依赖、API配置、Word和预览工具。普通自检不调用API、不启动Word；“深入检测”才使用公开样本调用本机Word。已安装、已配置不等于实际调用成功。

先试 [两套开始使用样例](samples/start-here/README.md)：基础样例无需API或Word；完整样例复用已保存要求，需要本机Word才能完成目录更新和PDF。无需从几十个历史阶段目录中找文件。

## 两个入口怎样选

- **智能排版**：上传论文，点击“开始智能排版”，完成后“下载修正版”。需要判断时在同页集中回答。需要时使用AI，可靠本地部分不要求联网。
- **本地精细工作台**：默认零API；依次编辑要求、确认范围、查看问题、明确选择修正、预演采用、下载。保留完整规则、保护、布局辅助、历史和项目控制。可选AI工具只有明确点击才联网。

新任务默认补入**普通图题、表题居中**（PaperFit项目默认，非学校明文要求）；已保存/导入要求、人工关闭和用户覆盖优先。新版完整整理也检查安全内容表左右外侧边框、内部目标及题注结构。仅格式路径不自动处理边框或布局。

新任务默认智能完整整理：文字格式、安全图表与分页辅助、安全编号同步、分区页码及本机Word目录/引用更新。开始前会显示本次处理集合；点击开始才授权执行。折叠的“调整处理内容”可以选择“仅整理文字格式”，或调整页码、章节页脚和Word更新。旧项目按原选择恢复，不自动扩大操作。复杂或范围不明的对象保持，不会为了凑完整清空内容或强行修改。

## 如何使用老师的要求

默认沿用当前要求。项目内SCUT演示规则来自2015年本科工理类材料，**不代表现行全部校规**。

也可填写支持范围内的补充文字，上传TXT/DOCX要求，或上传“保存这套排版要求”得到的规则包。未提及属性沿用当前值；冲突、提取遗漏或不能执行的要求会说明，不会默默忽略。复用保存要求不再请求规范解析API；论文结构有歧义时仍可能需要结构识别。

安全自动目录可采用项目默认外观：标题居左、页码右对齐、原生点状引导线和分级缩进，按所在节的实际正文宽度设置。这是产品默认，不冒充SCUT强制要求。本地目录工具可选择保留原格式；复杂分栏、锁定/绑定容器等保持并说明。没有Word时不宣称目录页码已经核验。

## 下载、预览和继续处理

**DOCX准备好即可下载**，不必等PDF。PDF仍生成或失败不会撤回合法DOCX。结果首屏提供DOCX、Word页面/PDF状态、主要调整及剩余事项分类；完整数量、记录、原始报告和更多文件可展开查看。

- 本机Word用于支持的目录/REF/PAGEREF更新、Word原生PDF和页图。仅操作本任务副本，不全局关闭Word，不保存用户其他文档。
- LibreOffice是可选备用预览；与Word字体、分页可能不同，界面明确标注引擎。同页号不表示自动对齐内容。
- 下载由浏览器保存到您选定的文件夹。未主动下载的任务在仓库 `work/web/`，启动状态日志在 `work/local/`，均不提交Git。请及时保存DOCX或项目，不把任务目录当长期备份。
- “保存项目”用于恢复原稿、已保存规则/范围和历史；“保存排版要求”只复用要求。恢复不自动调用API/Word，也不恢复旧执行授权，需要重新开始或检查。
- 当前处理输入与最新输出分开。只有明确点击“以此副本继续处理”才切换输入。查看历史、预览、下载均不切换。

## API与真实边界

DeepSeek由管理员通过本机 `.env` / 环境变量管理。智能按钮附近说明发送用途；需要时仅发送有限脱敏文字摘录或格式要求，脱敏不保证彻底匿名，不上传整份DOCX。没有API时可用可靠本地处理；无法理解的补充不能悄悄忽略。不自动重试或升级模型。勿将密钥发到聊天或提交仓库。

支持的结构、范围和显式要求内才执行修改。复杂域、修订、锁定/绑定内容控件、未知编号和不可靠关联可能保持。只读检查与更新不同；PAGE存在不证明实际分页，目录生成不证明引用真实性。字体缺失、加粗描边、不同Word版本仍可能影响显示。不会自动改写论文、批量刷新任意域或修改自动编号定义；没有Word COM、PDF输入或OCR。

打不开、超时、PDF失败等请看 [故障处理](docs/troubleshooting.md)。遇到错误先保存已有合法成果和项目，不盲删缓存或结束全部Word进程。
