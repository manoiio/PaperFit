## 改变与状态口径

- 公共CSS统一深蓝主色、正文/标题/辅助说明层级、间距、圆角、卡片边框和按钮高度。辅助说明明确设置正文元素颜色，提高对比度；用静态文字符号增加克制品牌识别。原生控件、问题对比、阅读区沿用同一风格，没有CDN、外部字体、图标依赖、生成class或nth-child。
- 顶部将**尚未载入、范围待核对且尚未检查、范围已确认但尚未检查、已有有效检查、原检查当前不可用**分开。只有UI在同一任务/输入哈希/轮次确实观察过真实检查，随后报告不可用时才显示最后一种；不猜具体原因。新任务/输入/轮次重新建立UI观察，项目包不保存它，更不恢复为授权。原文件/规则校验仍由原业务路径执行。
- **当前输入、最新正式记录、查看目标**分别显示。最新记录额外核对输出文件实际哈希；只有输入轮次和内容哈希均匹配才标为已是当前输入，不能只因相同字节或result存在便推断切换。缺失/改动输出说明文件不可用。此显示不代替原下载校验。
- 预演记录未采用不会显示成正式输出；采用后只描述登记轮次和真实输入关系。历史与预览目标各有查看身份，查看不切输入。范围编辑后提示重新核对要求和范围，不把旧记录用于当前操作。
- 导航区分当前、可进入、已确认范围、有记录、需载入/检查/记录；禁用项说明缺少前提。可进入不等于完成，回看不重置业务流程。保存/返回/导出仍为次操作；确认范围、预演、采用和继续输入保持原独立授权。
- 首页说明本地选择修正流程并突出上传/合成样本；统一筛选为空、未选修正、无本轮输出、无有效预览的空状态。筛选无结果仍保留筛选外选择；0格式问题仍显示待复核、未检查和实际分页边界。风险、复杂对象和必要确认没有隐藏。
