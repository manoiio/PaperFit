## 实际改变

- 左侧默认可见原生对象列表，每页最多20个，固定高度内滚动。显示位置、短文本、全部状态各自记录数量、该对象已选数，当前项高亮。统计包含当前筛选隐藏的状态，不能拿第一条待复核或可修正问题代表整个对象。
- 右侧检查项直接列出，每页4条；以稳定记录ID查看“实际 → 要求”、原因、处理方式。具体属性旁明确“加入修正 / 移出修正”；查看、翻页、排序不勾选。只读问题、待复核、输出副本和独立辅助分别说明，不扩大自动修正。
- “已选 N 项 · 查看清单”直接读取原`model.selected`及`eligible`，包含其他页、筛选外项目，每页8项，可逐项移除或明确清空。查看清单不改变筛选/输入；预演仍包含全部明确选择，原预演核对与采用授权保留。
- 批量入口明确区分本页、当前筛选全部页、当前输入全部可修正项，并显示实际数量。高级兼容选择器保留（本页最多100条），其余可由分页详情及明确批量操作选择。原始执行清单、对象完整技术表仅主动载入后生成；完整报告不裁减。
- 原关键词、类别、状态、类型、编号、排序和分页能力保留；“更多筛选”可清除，空结果/非法编号也有恢复入口。清除不清修正选择。有效对象/记录ID与文件、规则、任务、报告、筛选及页绑定；不可见旧对象回到有效对象。查看偏好跨步骤保留，授权勾选不保留为新授权。
- 输出副本与当前输入不同哈希时不能用同key勾选输入问题，批量添加禁用，原稿选择单独说明。只有原有明确继续操作才能切输入。原宽度、分页、题注等高级入口仍可访问。

原生Streamlit，无新依赖、CDN、外部字体、生成class或nth-child；少量CSS限定稳定容器key。文件/文档片段的原生Markdown标签转义；“实际→要求”继续由原公共组件HTML转义。未建立第二套选择状态、分类器或引擎。
