## 实现边界（验收前已固定）

- 普通格式与原精确数字事务不放宽。新增页码是独立结构事务；Package旧bytes()不新增成员，新structure_bytes()只允许主文档、主关系、内容类型及受控footerPF部件/关系。
- 分节附在边界之前已有普通段落的pPr内，不新增段落或重排对象。以原section归属克隆纸张、边距、页眉引用、栏和其他设置；存在注释按节重启、行编号、复杂边界或独立分页空段时拒绝自动拆分。
- 默认、首页、偶数页页脚分别隔离克隆；不全局关闭首页/奇偶差异，不改原共享部件。只有PAGE专用普通段可安全替换；图形、表格、书签、修订、复杂PAGE、多个PAGE、页眉PAGE或混合文字冲突会集中询问保持原页码。
- 新PAGE无伪造缓存数字，不设置updateFields。pgNumType使用decimal/lowerRoman/upperRoman及明确start；后续章未要求重启时删除冲突start，保持连续。仅要求章节页脚时保留编号设置，不顺带隐藏封面或改罗马。
- keep表示保留本区原有编号声明及有效页脚；若它原本连续承接前节，而前节重启/分页变化，可见数值仍会随之变化，不能承诺旧物理页码不变。要固定数字需明确本区起始值。
- 三条明确页码/章节页脚/数字同步语句可在本地精确证明，0规范解析请求；其余格式仍走既有短ID。TXT/DOCX保持原位置与原文，未知、冲突不当背景丢弃。规则包只保存策略，不保存论文起点；项目保存本篇草稿和历史，恢复不执行。

## 真实流程与实际结果

保留两个入口，没有第三套任务页。新任务/旧包默认“常规格式整理”，不改页码和编号。选择“完整整理”后，同一次开始授权普通格式、可证明完整的数字组及页码；必要起点/复杂页脚保持选择在原页集中问。高级本地第5步可准备/编辑分区、保存草稿、单独真实预演/采用，也可核对明确方案后批量处理；默认零API。

- 已有人工分类项目：正常UI恢复 → 选择完整方案和章节页脚 → 开始 → 下载。内部真实三轮：普通格式35处、编号/引用4处数字、页码结构12项。没有额外动态完整声明/预演/勾选采用。它复用已确认分类，不冒称新文档无人工识别。
- 新会话上传原稿：选择完整方案 → 开始 → 同页回答一次正文起点 → 下载。原样本没有关键词边界，先前本地分类把后文留在摘要区域；明确正文边界后按同一分类器重分析未确认范围，保留人工调整和材料排除。图题无可靠图片关联的两组保留待核对：35格式、0数字、12结构，最终2问题29待复核；不能以生成页码代表图表编号已整理。
- 已确认完整范围样本：最终仍1问题27待复核（旧只读校规/支持边界等），不强求全绿。当前输入始终原稿，输出是第3轮；各阶段输入为上一实际输出，全部父子哈希可追溯。
- 本地真实UI：服务重启 → 拖放恢复实际保存项目 → 三轮历史和草稿保留，但当前正式结果未恢复为执行授权，实际重新检查原稿 → 第5步准备分区/真实预演/取消 → 明确批量授权处理。独立结果与智能相同方案对照，不调用AI。

## 回归与剩余限制

新增聚合测试覆盖结构精确白名单、已有/单节、首页/奇偶继承隔离、重复幂等、外改副本/草稿拒绝、原子归档失败、项目/规则复用、零API文本/TXT/DOCX、自动数字REF和不完整范围阻止及集中例外。保留原1311场景；发现旧结果页UI状态兼容问题和新结构证明显示遗漏后修复，未放宽旧保护断言。最终完整结果见本页收尾记录。

不能处理：复杂边界/表格内部插节、图形或混合PAGE页脚、章节前缀页码、页眉PAGE位置冲突、注释按节重启或行编号影响、真实页码计算/目录更新/引用域刷新。keep维持原声明与有效页脚，不保证连续承接时可见数字永远固定。新结构只允许已有主文档段落边界，不为未知内容猜分区。当前SCUT演示来源有页码位置歧义，页脚居中是明确产品选择，不冒充校方唯一规定。

实现对照：[Microsoft节页码格式/起始值](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.pagenumbertype)、[Word分区页码和链接到前节](https://support.microsoft.com/en-gb/word/customize-page-numbers-and-their-formats-in-different-word-document-sections)、[独立页眉页脚](https://support.microsoft.com/en-gb/word/configure-headers-and-footers-for-different-sections-of-a-word-document)。这些说明支持结构语义，不替代本项目真实文件验收。

额外回归修复：正文中有表格时，XML body对象序号不同于顶层段落编号。新增/原有节起点判断改为已有段落身份集合；章节页脚单独处理时，不会误清后续原有节的重启值。保护案例在正文插入表格并手写后章start=7，核对其值及表格子树保持。原普通格式结果签名不包含仅查看默认页码面板的空UI草稿；新完整命令和页码预演则继续绑定实际方案、范围及执行版本。
