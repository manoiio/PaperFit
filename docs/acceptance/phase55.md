# 第55阶段：目录外观与智能入口精简

基线main/9a4d5c7，1411项。原工作区干净。无付费API、部署或远端CI。先核对旧方案和目录实际发布路径，再实现入口映射、目录缓存外观、恢复保护，最后验收真实下载与Word窗口。

## 入口与旧方案映射

新任务默认完整整理：**上传 → 开始智能排版 → 下载修正版**。开始前显示本次集合，只有真实歧义才同页询问。默认折叠“调整处理内容”，可直接选择“仅整理文字格式”；其余按图表/编号、页码/页脚、Word更新三组控制，页码细节按需出现。没有新增导航或另一套引擎。

| 原保存值 | 当前位置与兼容含义 |
| --- | --- |
| current | 仅整理文字格式；编号、页码、目录保持 |
| complete_safe | 新任务完整整理默认；安全图表、相邻、编号、分区页码、Word更新 |
| complete_safe_chapters | 同上，正文页脚保留“章节名称＋页码” |
| complete | 原版本格式/编号/页码集合保持；不会自动增加图表辅助 |
| complete_chapters | 原集合及章节页脚保持；不会自动增加图表辅助 |

旧策略的版本、适用区段、起始值、连续/重启、页脚文字和人工范围原样读取。旧数据没有目录外观字段时保留原格式。更早v1/v2策略若无Word更新记录/明确开关，不推断后来功能的授权，需在折叠区明确开启；v3完整方案保持原有Word能力。旧项目恢复不执行、不恢复采用授权。新选项为现有项目编辑草稿的可选字段，旧包兼容，未知值仍拒绝。

“重新开始”清除本任务处理选项，回到新任务默认；换文件保留明确设置时仍清空不匹配的实际分区起点，并由新开始命令绑定。查看历史、预览、切入口不切换输入。精细工作台保留原高级方案、范围、所有辅助、单轮/两步预演和下载，默认零API。

## 目录实际发布实现

在word_fields的受限回填中补齐，不发布Word全量另存包，也不只改计算临时文件。

- 使用w:tab、右对齐制表位和dot leader；没有拼接句点、空格或省略号。
- 复用宽度模块的真实节归属、纸张、左右边距和装订线，减去目录段落右缩进。制表位不是固定A4数值。
- 缺失的一级至三级左缩进为0/360/720twips；已有合理缩进、正确点线制表位优先保持。字体字号及其他pPr属性沿用原有设置。这是**项目默认外观，不是SCUT强制要求**。
- 给自动编号显示值与标题之间保留独立左制表位；页码使用末端右制表位。长标题自然换行。
- 直接目录、普通块级目录控件及已确认普通手工条目转换共用make_toc发布路径；容器外壳、目录标题、原域指令和目标保护保持。
- 后续刷新通过真实书签目标身份恢复条目层级，不依赖文字匹配或旧行号，避免无TOC样式ID的已发布条目刷新后丢失外观。
- 未存储定义的明确Word内置TOC1–3只局部显式设置几何，不推断字体，不全局修补styles.xml。其他未知继承、多栏、镜像/异常边距、字符缩进、非普通方向、目录自身编号等保留并记录原因；锁定/绑定/复杂控件仍不更新。

外观、页码更新分别进入修改记录和复查。最终回填文件再次由Word测量，使用原有4遍上限稳定性检查；目录加长引起的分页变化仍须稳定才发布。复杂分节边界现在进入已有集中取舍问题，不能安全设置时允许明确保留页码继续其他步骤，未放宽结构白名单。

另用真实Word验证7200twips窄正文区和明确普通手工目录转换；新增点线进入最终副本，其他ZIP成员及未授权主文档子树保持。自动编号内容控件目录的既有正确外观保留；字符单位/未知继承阻止标准外观时，外观总状态为保持，明细试算不代表已写入。

原生点线及制表位语义参照[Microsoft Word说明](https://support.microsoft.com/en-us/word/show-dots-or-leaders-between-tabs)及[Wordprocessing TabStop](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.tabstop?view=openxml-3.0.1)。最终效果另经本机Word实测。

## 实际验收

公开小样本独立编写，含三级标题、长标题及过期目录；不含指定本地演示论文衍生内容。新上传不导入作者确认项目，默认3项主要操作（文件选择计1项），无额外决定或高级工作台。4轮：普通格式59项、分区结构5项、相邻2项、目录缓存/外观2项；不同操作不是独立解决问题数。仍有3问题、9待复核，不称全文合格。

仅格式路径：上传、展开调整、选择仅格式、开始、下载共5项操作；1轮59项修改，0 Word/0 API，原过期目录保持。同配置原fix_document路径下载逐字节一致。早期脚本将上传和后续点击挤在同一轮重运行，未实际选中仅格式；改用可见状态逐步操作后完成，不把误操作算通过。

真实本地工作台编排execute_local＋原Word预演/采用，与智能同一最终范围/策略得到同字节输出（a50a249e…），4轮，19.376秒；公开智能复现21.876秒，单次观察不计算提速率。真实Word再次刷新且选择保留外观，DOCX逐字节不变。项目保存恢复后历史第4轮下载同字节，不自动执行Word/API；当前输入仍为原稿。独立会话分别保留自己的文件、范围和结果。

1280×720、1440×900真实浏览器核对，无页面级横向溢出。主入口无五选一；DOCX、目录外观状态和剩余项真实展示。无私有session_state注入；AppTest属于另列受控回归。

## 测试及限制

针对性：目录/恢复/绑定10项、智能UI3项、内容控件11项、页码15项、本地交付13项通过。相关自动测试硬拦截付费HTTP与真实Word；真实Word集成另记。冻结前数次提前全量运行在发现重置、后续刷新及方向/旧授权边界后中止，均不计完整通过；只以最终冻结后的完整结果为验收。

最终冻结产品源码完整离线 **1422项通过，752.728秒**，包含原1411项；真实付费HTTP/Word及漏模拟调用均0。独立只读核对脚本另补充了“无直接缩进节点”时报告未知而不猜继承的分支，已重核公开/编号目录。仓库链接、夹具及diff审计通过，提交后另核对远端SHA。不触发远端完整CI。

仍保持复杂域、锁定/绑定控件、多栏等边界。无Word时可保留合法普通排版成果，但不能声称页码已实际核验。本轮不新增付费AI、排版规则、Word动态类型或跨文档批量功能。
