# 一次论文整理怎样完成

双击仓库里的“启动论文有格.command”，等待打开本机网页。

## 智能排版

1. 上传待排版DOCX。
2. 沿用页面显示的要求，点击“开始智能排版”。
3. 下载修正版。DOCX可先下载，不必等PDF。

新任务默认完整整理当前安全适用的文字、图表、分页、编号与页码，并在本机Word可用时更新支持的目录和引用。少量无法判断的事项在原页集中询问；回答后继续，不重新分析整篇论文。不支持或未授权的对象保留，并列入剩余事项。

只想改普通文字？打开“调整处理内容”，勾选“仅整理文字格式”。也可调整页码起始值、章名页脚、Word更新和目录外观。原来的五种方案已合并为这里的控制；新任务不用先选方案，旧项目不会自动升级。

目录外观“项目默认”使用Word原生右对齐制表位及点线，按目录所在节的正文宽度计算，补齐缺少的层级缩进。合适的已有设置优先保持。它不是学校强制数值；字体、字号等沿用已有要求。目录外观和实际页码复查分别记录。缺少Word仍可下载安全排版结果，但目录/引用可能未完成更新。

可选补充文字、TXT/DOCX要求及保存要求继续使用原入口。没有API时可靠本地部分仍可用；自定义要求不能理解时需要明确取舍，不会悄悄忽略。需要AI时只发送按钮附近说明的有限摘录，不上传整份DOCX。

## 本地精细工作台

默认零API。五步工作区保留规则、范围、问题筛选与跨页选择、真实预演、明确采用、所有安全辅助和历史。

结果页的“本机Word · 目录与交叉引用更新”可以选择具体目录/引用及“保留原目录格式”或“项目默认”。创建/转换只适用于已确认普通目录区域，位置不明或复杂内容保持。

## 继续与恢复

查看历史、预览和下载不会切换当前输入。只有明确“以此副本继续处理”才进入下一轮。

保存项目可保留已保存规则、范围草稿、处理选项和历史；恢复后重新核对，不自动启动AI、Word或恢复旧授权。历史目录的外观仍在原DOCX中。点击“重新开始”是新任务，处理选项回到新任务默认值；不要把任务目录当长期备份。

详细恢复办法见[故障处理](troubleshooting.md)。这些功能不保证任意论文全文合格，也不代替学校要求和最终Word人工核对。
